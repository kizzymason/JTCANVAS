# TODO

本文档用来记录当前项目后续比较值得处理的事项。

- 支付渠道对接：`orders` 表已预留 `payment_provider` 字段，钱包充值弹窗的在线充值区域也留了位置，接微信 / 支付宝时不需要改表结构；目前只有卡密兑换与管理员手工调整两种入账方式。
- PiAPI 账号池后续：目前在导入、手动刷新和每次生成成功后校准余额，没有定时巡检；账号数量多时可以考虑批量并发上限和定时刷新策略。
- 生成工作台的历史记录仍是浏览器本地缓存：权威记录已经在服务端（我的钱包「使用记录」与管理后台「生成记录」），但生图 / 视频工作台左侧的历史列表还读本地 localforage，换设备看不到。后续应改为直接读服务端生成记录。
- 存储迁移工具：管理后台可以切换本机磁盘与 S3，但切换只影响新文件，已有文件不会搬迁，需要一个后台迁移任务。
- 画布协作与冲突体验：目前用 `version` 乐观锁，冲突时提示用户刷新。多设备同时编辑同一画布的体验还比较粗糙，后续可考虑增量补丁或字段级合并。
- 本地 Agent 接入后续：按[本地 Agent 接入规划](/zh-CN/docs/progress/local-agent-integration-plan)把 Claude Code CLI Adapter 升级为 Claude Agent SDK Adapter，并完善工具队列体验。
- 平台自有 Agent：前台入口已改由管理后台「服务管理」控制（默认开启），待接入平台自有 Agent API 后再替换本地 Codex 对接；不要删除 Agent 相关代码。
- 画布节点插件入口：前台已用 `NODE_PLUGIN_UI_ENABLED` 隐藏画布顶栏「节点插件」和底部「扩展节点」，待插件产品就绪后再打开该开关，不要删除插件相关代码。
- 本地 Agent 协议与服务端计费的衔接：Agent 的生成工具现在会走服务端接口并扣费，协议版本需要从 6 升到 7 并在面板上体现余额不足的情况。
- Agent Skill 后续：补充网络检索安装、Skill 资源文件管理和可控的本地记忆沉淀。
- 画布插件仍是任意远程 URL 动态 `import()`：商业化后应改为仅允许管理员在后台登记的白名单插件。
