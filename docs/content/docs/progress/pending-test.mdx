## Commercialisation (the largest change in this release)

The project moved from browser-local and browser-direct to a server-authoritative model with a login wall and metered billing. Almost every path changed, so the whole flow is worth walking through.

- Accounts and access: the entire app requires a sign-in except the homepage; login and registration share a homepage dialog with a small-radius rectangular sliding toggle; the first registered account becomes the administrator; new users start at zero balance and cannot generate until they top up; changing a password or being disabled by an admin revokes every session immediately; the top navigation shows the current balance and opens a narrow My wallet drawer (also on the canvas). - Cloud data: canvases, assets and generated files all live on the server and follow the account across devices; canvas saves are per project and panning does not write to the server; concurrent edits of one canvas produce a version conflict rather than a silent overwrite; ZIP import re-uploads files under fresh storage keys; the account page offers a one-time import of leftover browser-local data.
